# 一起看 · 两个人的小影院

异地恋同步看片小站。两个人各自播放同一个片源，只同步"播放 / 暂停 / 进度"指令，
原画画质、几乎不费流量，网页打开就能用，手机电脑都行。

## 为什么不是屏幕共享

屏幕共享是把电影画面实时重新编码推一遍：画质缩水、流量巨大，而且 iPhone 的
浏览器不允许抓屏幕。同步播放只传几字节的心跳指令，画质是各自的原画。

## 本地试跑

```bash
npm install
npm start        # 默认 3000 端口，可用 PORT=8080 改
```

- 电脑浏览器打开 `http://localhost:3000`，输入昵称 → 创建房间
- 手机连**同一个 WiFi**，打开 `http://<电脑局域网IP>:3000/?room=房间码` 加入
- 屋主"选片"：贴一个视频直链，或两边选同一个本地文件
- 屋主导播：播放 / 暂停 / 拖进度都会同步，每 5 秒心跳自动纠偏

## 异地部署（需要一台 VPS）

阿里云/腾讯云轻量服务器即可（国内直连快），安全组放行端口后：

```bash
npm install --production
pm2 start server.js --name yiqikan
```

建议用 Caddy 套一层 HTTPS（两条配置的事）：手机上震动、剪贴板这些 API
只在 HTTPS 下生效。

## 片源从哪来

v1 支持两种：视频直链（mp4/webm），或两人各自本地选同一个文件。
片源请自行准备。想接 Jellyfin 媒体库或网盘直链，见下面的路线图。

## 路线图（专属定制点都在这）

- [ ] WebRTC 连麦语音，边看边聊（第一版先用微信语音顶着）
- [ ] 视频上的悄悄话气泡 / 小弹幕
- [ ] 观影手账：一起看过的片、累计时长、追剧清单
- [ ] 小挂件：两只小人趴在进度条上，戳一下对方屏幕会震动
- [ ] HLS(m3u8) 支持（引入 hls.js）

改哪里：房间/同步逻辑在 `server.js`（约 150 行），界面和交互在 `public/app.js`。
